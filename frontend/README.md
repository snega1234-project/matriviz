# 🎨 DataVista Frontend (Interactive CSV & Chart Studio)

Modern web interface for uploading CSV datasets, mapping X and Y axes, and visualizing statistical charts generated by the Python Seaborn backend.

---

## 💻 Tech Stack

- **Markup**: Semantic HTML5 with accessible IDs and ARIA labels.
- **Styling**: Vanilla CSS with modern Design Tokens, Glassmorphism (`backdrop-filter`), Responsive CSS Grid & Flexbox, and Dark/Light Mode.
- **Logic**: Vanilla JavaScript (Async/Await Fetch API, `navigator.sendBeacon`, DOM Manipulation).
- **Libraries**:
  - [Chart.js](https://www.chartjs.org/) (for optional interactive canvas toggle mode).
  - Google Fonts: *Plus Jakarta Sans* & *JetBrains Mono*.

## 🌟 Key Features

### 1. Drag & Drop CSV Upload
- Validates strictly `.csv` files.
- Automatically sends file to `POST http://127.0.0.1:5000/api/upload`.
- Displays file name and size metadata badge.

### 2. Dynamic Axes Selection (From Pandas)
- Populates **X-Axis** and **Y-Axis** dropdowns dynamically using column names returned by Pandas.
- Automatically highlights numeric columns (`[123]`) and text columns (`[ABC]`).
- Intelligent auto-selection picks categorical columns for X and numeric columns for Y.

### 3. Chart List (Clean & Friendly Types)
Select from 8 statistical visualizations:
- 📊 **Bar Chart**
- 📈 **Line Chart**
- 🥧 **Pie Chart**
- 🍩 **Doughnut Chart**
- 🟣 **Scatter Plot**
- 📉 **Area Chart**
- 📶 **Histogram**
- 📦 **Box Plot**

### 4. Seaborn In-Memory Display & Toggle
- Renders the Seaborn chart received as a base64 byte stream directly into an `<img>` tag without saving any image files to disk.
- Includes a toggle button (**🎨 Seaborn Plot** ⇄ **⚡ Interactive Chart**) to switch between the Seaborn image and an interactive HTML5 canvas.

### 5. Automatic File Cleanup on Refresh
- Uses `beforeunload` and `pagehide` browser hooks with `navigator.sendBeacon()` to notify the backend to delete the active CSV file whenever the user refreshes or closes the page.

### 6. Data Table Preview & KPI Cards
- Displays NumPy-computed metrics: **Total Rows**, **Total Columns**, **Sum**, and **Mean**.
- Scrollable data table preview displaying the first 50 records of the uploaded dataset.
- Real-time instant search box to filter records across columns.
- **Export PNG** button to save charts locally in one click.

## 🚀 Running the Frontend (No Node.js Required)

This is a **pure Vanilla web application** (HTML5 + CSS3 + ES6 JavaScript). It requires **NO Node.js, NO npm, and NO dependencies**.

To serve the frontend locally:

```bash
cd frontend
python3 -m http.server 3300
```

---

### 🌐 Access in Browser
Open your browser and navigate to:
```
http://localhost:3300
```

> **Note**: Ensure the backend Flask server is running on port **`5000`** before uploading files (`http://127.0.0.1:5000`).
The status indicator in the top navbar will display:
`Backend: Connected (api.py + analysis.py)`.
